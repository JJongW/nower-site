자주 묻는 질문

iPhone과 Mac의 일정이 안 맞아요.
두 기기가 같은 Apple 계정으로 iCloud에 로그인돼 있고, iCloud Drive가 켜져 있는지 확인해 주세요. 네트워크 상태에 따라 반영까지 몇 분 걸릴 수 있어요.

Mac 캘린더 일정이 안 보여요.
Nower 설정에서 Apple 캘린더 연동을 켜고, 시스템 설정 → 개인정보 보호 및 보안 → 캘린더에서 Nower를 허용해 주세요.

알림이 안 와요.
시스템 설정 → 알림 → Nower에서 알림이 켜져 있는지 확인해 주세요. 알림은 시간이 정해진 일정에만 걸 수 있어요.

로그인할 때 자동으로 열리게 하고 싶어요.
Nower 설정 → 일반 → "로그인 시 자동 실행"을 켜 주세요.

바탕화면에 달력을 고정하고 싶어요.
창 위쪽 도구 막대의 고정 버튼을 눌러 주세요. 다시 누르면 일반 창으로 돌아와요.

FAQ

My iPhone and Mac don't match.
Make sure both devices are signed in to iCloud with the same Apple Account and iCloud Drive is on. Changes can take a few minutes to arrive.

I can't see my Mac Calendar events.
Turn on Apple Calendar in Nower Settings, then allow Nower in System Settings → Privacy & Security → Calendars.

Alerts don't appear.
Check System Settings → Notifications → Nower. Alerts are available for events with a set time.

Open Nower at login.
Turn on "Launch at login" in Nower Settings → General.

Pin the calendar to my desktop.
Click the pin button in the window toolbar. Click it again to return to a normal window.
